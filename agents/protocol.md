# Protocolo común de mensajes

Cada mensaje debe contener: identificador único, agente emisor, agente destinatario, fecha y hora, tipo de mensaje, identificador de tarea, objetivo, instrucciones, prioridad, estado, resultado o motivo de bloqueo.

Estados: Completada / Parcial / Bloqueada.

Nova revisa cada entrega antes de presentarla como aprobada. Los cambios rechazados no se incorporan a producción.
